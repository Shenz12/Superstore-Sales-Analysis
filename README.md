# Superstore Sales & Profit Dashboard

## Project Overview

Interactive Power BI dashboard developed as part of Data Analyst Internship Task 4.

## Tools Used

- Microsoft Excel
- Power BI
- DAX
- PowerPoint

## Data Cleaning

The dataset was cleaned in Excel by:

- Checking missing values
- Removing duplicate records
- Standardizing date formats
- Formatting numerical fields
- Checking categorical values
- Converting the dataset into an Excel table

## Dashboard Pages

### 1. Executive Dashboard
- Total Sales
- Total Profit
- Total Orders
- Profit Margin
- Sales & Profit Trend
- Category Analysis
- Regional Analysis
- Segment Analysis

### 2. Product Analysis
- Sales by Sub-Category
- Profit by Sub-Category
- Top 10 Products
- Bottom 10 Products
- Discount vs Profit

### 3. Regional Analysis
- Sales by Region
- Profit by State
- Sales by Ship Mode
- Customer Segment Analysis

## Key Insights

- Technology is the highest-performing category.
- West is the strongest region.
- Furniture has comparatively lower profitability.
- Sales increased significantly during 2025 and 2026.
- Tables is a loss-making sub-category.
